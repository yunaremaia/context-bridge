# Treasury

## Solana Wallet

`Eeztv1nCYUt1fwGWpzKC948gaWfjejYCAuLtUMgzDWbW`

Use this address to send SOL or SPL tokens to the project treasury.

## Purpose

The treasury manages project funds for:
- bounties and grants
- infrastructure costs
- long-term sustainability

All transactions are on-chain and transparent. See the [Solana Explorer](https://explorer.solana.com/address/Eeztv1nCYUt1fwGWpzKC948gaWfjejYCAuLtUMgzDWbW) for transaction history.
